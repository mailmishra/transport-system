The included responsive PWA prototype demonstrates the requested workflow:
Loading Slip -> Bilti/GR -> Agent/Dalal Ledger -> Truck Owner Ledger -> Final Receipt -> Reports.

Dalali is visible on the Bilti. FD (Freight Difference) is an internal field and is excluded from printing while remaining in the accounting ledger.

IMPORTANT:
This prototype stores data in the browser's local storage. For real multi-user use from mobile/laptop/desktop with shared data, it must be connected to a hosted database and authentication/API. The UI and accounting workflow are prepared as the foundation for that deployment.
